# Gravity Pop! — Official Website & Legal Pages

This repository contains the official landing page, player support portal, Privacy Policy, Terms of Service, and AdMob `app-ads.txt` for **Gravity Pop!**.

## How to Publish for Free on GitHub Pages (60 Seconds)

1. Create a new public repository on GitHub named `gravity-pop` (or `gravity-pop-website`).
2. Push all files in this directory to that repository:
   ```bash
   cd /Users/dabba/Documents/Projects/gravity-pop-website
   git init
   git add .
   git commit -m "Initial commit of Gravity Pop website & legal assets"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/gravity-pop.git
   git push -u origin main
   ```
3. Go to your repository on GitHub:
   * Click **Settings** → **Pages** (on the left menu).
   * Under **Build and deployment** > **Branch**, select `main` and root `/` folder, then click **Save**.

Your free live website will be up in 1 minute at:
`https://<YOUR_GITHUB_USERNAME>.github.io/gravity-pop/`
