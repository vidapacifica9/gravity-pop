## Free GitHub Pages Hosting (Step-by-Step)

1. Create a new public repository on GitHub named:
   👉 **`gravity-pop-website`** under your account (`vidapacifica9`).
2. Run this single command in your terminal to push:
   ```bash
   cd /Users/dabba/Documents/Projects/gravity-pop-website
   git push -u origin main
   ```
3. Enable GitHub Pages:
   * In your repository on GitHub, click **Settings** → **Pages** (in the left sidebar).
   * Under **Build and deployment** → **Branch**, select `main` and root `/` folder, then click **Save**.
